Belvedere Glacier – data API

Monitoring data of the Belvedere Glacier (Macugnaga, VCO, Italy) · LabMGF, Politecnico di Milano

  • Project website
  • Web map
  • Open data on Zenodo
  • Staff admin

This server holds the project's GNSS survey data and time-lapse camera catalogue. The endpoints below return JSON, need no key, and can be called from any website (CORS is open). {% if first_year and latest_year %}Surveys with measurements cover {{ first_year }}–{{ latest_year }}.{% endif %}

GNSS surveys

GET/surveys/years/

Years of the survey campaigns that have measurements, ascending.

Example: {% url 'surveys:years' %}

GET/surveys/measurements/

All point measurements, one object per point and survey (not paginated). Parameters: year (survey year), is_fixed (true = stable reference marks, false = points moving with the glacier).

{% if latest_year %}

Example: {% url 'surveys:measurements' %}?year={{ latest_year }}&is_fixed=false

{% endif %}
FieldMeaning
id, point_id, labelMeasurement id, point id and point label (e.g. D12).
is_fixedTrue for stable reference marks, false for points on moving ice.
east, northPosition, m, RDN2008 / UTM zone 32N (EPSG:7791).
hEllipsoidal height, m (GRS80).
h_ortoOrthometric height, m, referred to the ITALGEO05 geoid.
lat, lonDecimal degrees (WGS 84; numerically identical to RDN2008 geographic).
std_east, std_north, std_hStandard deviations, m (when available).
survey_id, survey_date, survey_yearThe survey campaign.
meas_date, meas_timeWhen the point was measured (meas_time in UTC); often empty for older campaigns.
meas_strategySurvey mode, e.g. RTK RADIO, STATICO.

GET/surveys/points/<label>/velocity/

Yearly horizontal velocity of a moving point, one object per pair of surveys about a year apart: survey_year (year of the later survey), survey_date_ini, survey_date_fin, v in metres per day (× 365.25 for m/yr). Empty for fixed or unknown points.

{% if example_point %}

Example: {% url 'surveys:point-velocity' example_point %}

{% endif %}

Reference systems

GET/georef/reference-systems/

The coordinate reference systems the data is expressed in (EPSG codes, names, use), the height references (ellipsoidal h, orthometric h_orto on ITALGEO05) and the local glacier frames (ENU, origin on D12) with the PROJ pipeline that converts geographic coordinates to them.

Example: {% url 'georef:reference-systems' %}

Time-lapse cameras

GET/cams/cameras/

The cameras: id, slug, camera_name, installation_date, is_active. Parameter active=true for active cameras only.

Example: {% url 'image_index:get-camera-list' %}?active=true

GET/cams/images/

Images of a camera, oldest first, paginated (500 per page, page_size up to 1000): id, datetime, filename, width_px, height_px, rotation. Parameters: camera (slug), date_after, date_before (ISO 8601).

{% if example_camera %}

Example: {% url 'image_index:get-image-list' %}?camera={{ example_camera }}&page_size=10

{% endif %}

GET/cams/images/<id> · /preview/ · /thumb/

The image itself: the original, a preview (up to 1280 × 960) or a thumbnail (up to 160 × 120). /preview-url/ and /thumb-url/ return instead a temporary direct link (url, valid expires_in = 900 s).

Use and citation

The data and products of the Belvedere monitoring project are published as open data on Zenodo, doi:10.5281/zenodo.10817029, under the GNU GPL v3.0 licence. Please cite them, and for the project:

Gaspari, F., Barbieri, F., Fascia, R., Ioli, F., Pinto, L., and Migliaccio, F. (2025) Strategies for Glacier Retreat Communication with 3D Geovisualization and Open Data Sharing, ISPRS Int. J. Geo-Inf., 14, 75, doi:10.3390/ijgi14020075.

Fair use: anonymous clients are limited to 300 requests per minute on the JSON endpoints. For bulk downloads, prefer the Zenodo archive.
